# Backroom Operations Hub

**“Refocus the CRM to be a backroom operations interface on top of Airtable (system of record). The primary user is backroom staff who load and maintain Clients (Sponsors/Clients), Projects, Documents/Data Rooms, Tasks, Investors, Outreach/Meetings, Term Sheets, and KPIs.

The CRM must provide:

Pipeline (Kanban by Stage) for Projects

Client directory with linked projects

Project profile with linked Docs, Tasks, Outreach, Term Sheets, KPIs

Investor directory with contacts and outreach timeline

Task manager (My Tasks, By Project, Overdue)

Data Room per project (doc list with type/version/status)

Deal desk (active term sheets)

Portfolio monitoring dashboard

All reads/writes must sync to Airtable tables (no local DB).
CRM is internal-only (login required), no marketing pages.”**
